## Walkthrough

Two files changed:

### `internal/exponential/agents.go` — `GenerateAgentDocs()`

Rewrote the template that `xpo doctor` renders into downstream projects' agent instruction files (`.cursorrules`, `AGENTS.md`, `GEMINI.md`, `.github/copilot-instructions.md`, etc.).

**Before:** CLI-centric instructions (`./xpo list`, `./xpo start`, `./xpo done`), old 5-step workflow, no mention of specs/walkthroughs, included a repo-specific "Building the project" section derived from the `prefix` parameter.

**After:**
1. MCP tool table as primary interface — maps actions to `mcp__xpo__*` tool names
2. Full 6-step workflow: Discover → Plan → Start → Implement & test → Document → Complete
3. Seven strict rules (added: dependency checking, comment-before-complete, file-what-you-find)
4. Specs and Walkthroughs section — read specs before implementation, write walkthroughs after, use artifacts for supplemental files
5. Completion comments guidance (summary, rationale, continuation context)
6. Removed the `make build` / binary-name section — downstream projects have their own build systems
7. `prefix` parameter kept for API compatibility but no longer used

The detection marker `# Exponential Agent Instructions` is unchanged, so `DetectAgentFiles()` still correctly identifies files that already have xpo instructions.

### `AGENTS.md` (repo root)

Rewritten separately to match the current MCP-based workflow for this repo specifically. This file is not generated by `xpo doctor` — it's hand-maintained for this project's own agents.
