# Spec: Upgrade to v3 skill

## What

Update the skill content generated by `GenerateSkillMD()`, `generateWorkflowBody()`, and `generateMCPToolsBody()` in `internal/exponential/agents.go` to match the v3.1 reference skill at `/Volumes/Work/Repositories/github-nicbet/claude-skills/skills/xpo/`.

## Why

The reference skill has evolved to v3.1 with improved workflow structure, better gates, new features (rationale tool, issue labels, backlog review), and additional statuses (CANCELED, DUPLICATE). The generated skill is still at v1.0 and missing these improvements.

## Acceptance Criteria

- [ ] `GenerateSkillMD()` produces the v3.1 SKILL.md content (frontmatter: `name: xpo`, `version: "3.1"`)
- [ ] `generateWorkflowBody()` matches the v3 workflow structure (9 steps with updated names, gates, rationale tool usage)
- [ ] `generateMCPToolsBody()` includes the `rationale` tool
- [ ] `GenerateSpecGuide()` unchanged (already matches v3)
- [ ] `GenerateAgentDocs()` (full docs for skill-less agents) also gets the v3 content since it uses `generateWorkflowBody()`
- [ ] Existing tests pass
- [ ] `make test` passes

## Flow

1. Replace `GenerateSkillMD()` body with v3.1 frontmatter + content
2. Replace `generateWorkflowBody()` with v3 workflow steps + reference sections
3. Update `generateMCPToolsBody()` to add `rationale` row
4. Update any tests that assert on old content (e.g. `TestGenerateAgentStub_UsesNewHeading`)
5. Run `make test`

## Decisions

- **Content-only change** — no structural changes to types, functions, or command files. Just replacing the string content returned by the generators.
- **Spec guide unchanged** — the v3 reference `spec-guide.md` matches our current `GenerateSpecGuide()` output.
